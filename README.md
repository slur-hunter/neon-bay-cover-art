Neon Bay Cover Art is an original GTA 6-style cover art maker: turn your photo and a caption into a multi-panel poster with a Vice City sunset and neon colour grade, exported as a PNG to share. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No network requests: the app is plain static files under app/.
